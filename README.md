# Coquette Accessory

**E-commerce de accesorios y joyería**

Coquette Accessory es una tienda online desarrollada para un emprendimiento de accesorios y joyería.

El proyecto ofrece una experiencia de compra moderna, intuitiva y adaptable a cualquier dispositivo, combinando un diseño elegante y minimalista con funcionalidades que facilitan la exploración de productos y la gestión del catálogo.

### Tecnologías

HTML · CSS · JavaScript · Supabase
